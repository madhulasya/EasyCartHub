# EasyCart

**EasyCart** is a responsive static e-commerce shopping cart interface built using HTML and CSS.  
It demonstrates a modern and attractive UI design for an online store, including product display and cart preview.

---

## Project Description

EasyCart is a front-end project that showcases:
- Attractive product display layout.
- Responsive design that works on different devices.
- Clean, modern interface for browsing products.
- Basic shopping cart layout.

This project is purely HTML and CSS based, without backend integration.

---



## Installation Instructions

Since EasyCart is a static HTML/CSS project, there is no server setup needed.  
To view the project locally:
1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/easycart.git
    ```
2. Navigate to the project folder:
    ```bash
    cd easycart
    ```
3. Open `index.html` in your browser.
